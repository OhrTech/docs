You need an OhrTech organisation with at least one device, and permission to manage its members
(ManageMembers) in the OhrTech Portal.

<Steps>

1. **Create a service account.** In the [OhrTech Portal](https://portal.ohrtech.net), open
   **Service accounts** and create one named, say, `quickstart`.

2. **Grant it two permissions:** `ViewDevices` and `SendMessages`. Leave its devices, networks and
   embed sites unlimited for now. You can [narrow them](/management-api/permissions/) later.

3. **Make a token.** Choose **New token**, pick how long it lasts (30 days to a year), and copy it.
   It starts with `ohrs_` and is shown only once. Keep it in an environment variable:

   ```sh
   export OHR_TOKEN=ohrs_…
   ```

4. **List your devices.**

   <Tabs syncKey="lang">
   <TabItem label="curl">

   ```sh
   curl https://api.ohrtech.net/v1/devices -H "Authorization: Bearer $OHR_TOKEN"
   ```

   </TabItem>
   <TabItem label="C#">

   ```sh
   dotnet run quickstart.cs
   ```

   With [`quickstart.cs`](#the-whole-program) below. .NET 10 runs a single `.cs` file directly; there is
   no project to create.

   </TabItem>
   </Tabs>

   Each device has a `deviceId`. Pick one that is `online`.

5. **Show a message on its screen.**

   <Tabs syncKey="lang">
   <TabItem label="curl">

   ```sh
   curl https://api.ohrtech.net/v1/devices/dev_3swt6f457299btzpw1bxx4wf0q/messages \
     -H "Authorization: Bearer $OHR_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"text": "Hello from the Management API"}'
   ```

   </TabItem>
   <TabItem label="C#">

   ```sh
   dotnet run quickstart.cs -- dev_3swt6f457299btzpw1bxx4wf0q
   ```

   </TabItem>
   </Tabs>

   The message appears on the device within seconds. The response is the task that carries it:
   `GET /v1/devices/dev_3swt6f457299btzpw1bxx4wf0q/tasks/{taskId}` shows it go from `pending` to `success`.

</Steps>
