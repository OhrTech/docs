Auditors and customers ask the same questions: are all devices reporting, patched, configured as
required, up to date, and running your app? This program answers for every device, in a CSV you can open in a
spreadsheet or attach to your evidence.

**Needs:** a service account with `ViewDevices`, and .NET 10.

```sh
OHR_TOKEN=ohrs_… dotnet run compliance-report.cs -- com.example.yourapp > devices.csv
```

## How it works

For each device, `GET /v1/devices/{id}` gives its last check-in, OS build and security patch level,
OhrTech Agent version and whether its settings applied, and `GET /v1/devices/{id}/apps` its installed
apps. A device is compliant when it checked in within 24 hours, runs a security patch from the last
90 days, applied its current settings without errors, runs the current Agent and, if you name one,
has your app installed. `reasons` says why not.

## Make it yours

- Require a minimum version of your app by comparing `app_version`.
- Check particular settings: `GET /v1/devices/{id}/settings` shows each one's `reported` value and
  status.
- Keep the CSV from each month, as a record of your fleet's state over time.
