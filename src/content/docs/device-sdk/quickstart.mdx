## What the app needs

- **Android 13 (API 33) or later**, as above. OhrTech devices run Android 17.
- **An OhrTech device.** Elsewhere there is no OhrTech Agent, and calls throw
  `OhrException.Unsupported`. `OhrDeviceSdk.isAvailable()` tells you beforehand.
- **Installed through OhrTech by your organisation.** Upload the APK and assign the app to a fleet,
  in the portal or with the [Management API](/management-api/guides/apps/). The Agent answers only
  apps the hub installed on that device, signed with the key they were installed with; any other app
  gets `OhrException.NotManaged`. An update you install yourself during development, signed with
  the same key, keeps working; `OhrAccess.info().appVersion` is then null.

Exceptions are named as in Kotlin here. Dart and TypeScript name them `OhrUnsupported`,
`OhrNotManaged`, ...; C# `OhrUnsupportedException`, `OhrNotManagedException`, ...
([errors](/device-sdk/access/#errors)).

## Connect

There is nothing to connect, and nothing to close. Each area is an object you call directly:
`OhrDevice`, `OhrWifi`, `OhrKiosk` and the rest. The library binds the Agent on the first call, from
any thread, and keeps the binding for the life of your app's process. The application context comes
from AndroidX App Startup, which the library sets up in its manifest.

To know at app start whether the Device SDK is there, connect up front. It binds the Agent and asks
it who your app is:

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
// In a coroutine, at app start
if (!OhrDeviceSdk.isAvailable()) return                  // not an OhrTech device
try {
    OhrDeviceSdk.connect()                               // waits up to 10 s
    val access = OhrAccess.infoAsync()
    show("app ${access.app}, Agent ${access.agentVersion}, may use ${access.areas}")
} catch (e: OhrException.NotManaged) {
    // Not installed through OhrTech on this device
} catch (e: OhrException) {
    show("Device SDK: ${e.message}")
}
```

`connect` suspends, and is safe to call from the main thread. If your app removes the library's
App Startup initializer, call `OhrDeviceSdk.init(context)` in your `Application.onCreate`.

</TabItem>
<TabItem label="Java">

```java
// On a background thread, at app start
if (!OhrDeviceSdk.isAvailable()) return;                 // not an OhrTech device
try {
    OhrDeviceSdk.connectBlocking();                      // waits up to 10 s
    OhrAccess.Info access = OhrAccess.info();

} catch (OhrException.NotManaged e) {

} catch (OhrException e) {

}
```

`OhrException` is unchecked, so Java catches it without declaring `throws`. If your app removes the
library's App Startup initializer, call `OhrDeviceSdk.init(context)` in your `Application.onCreate`.

`connect` throws, and so does the first call when you don't connect up front:

| Exception | When |
|---|---|
| `OhrException.Unsupported` | The device has no OhrTech Agent with the Device SDK |
| `OhrException.NotManaged` | Your organisation didn't install this app on this device through OhrTech |
| `OhrException.Failed` | The Agent didn't answer within the timeout (10 seconds by default) |

`OhrAccess.info()` says who the Agent takes your app for: `app` (your app's `app_…` id),
`packageName`, `appVersion`, `agentVersion`, `agentInterface`, and `areas`, what the fleet lets it
do. It asks the Agent each time, so it shows a change of the fleet's grants at once.
`OhrAccess.mayUse("kiosk")` is true when the fleet grants kiosk mode. See
[access](/device-sdk/access/) for what each area needs.

## A first call

Read who the device is. Calls into the Agent are binder calls that wait for its answer. In Kotlin
and Java, make them off the main thread, or use the suspending `…Async` versions where there is one
([threading](/device-sdk/access/#threading)). In Dart, TypeScript and C# every call is asynchronous
already.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
val info = OhrDevice.infoAsync()   // or OhrDevice.info() off the main thread
show("${info.deviceId} in ${info.fleet?.name} (${info.org?.name}), Android ${info.osRelease}, " +
    "patch ${info.securityPatch}, online: ${info.online}")
```

| Field | |
|---|---|
| `deviceId` | The device's id, such as `dev_3swt6f457299btzpw1bxx4wf0q`. Null until the hub has sent the device its first policy |
| `serial` | The device's serial number |
| `fleet`, `org` | `id` and `name` of its fleet and organisation |
| `osRelease`, `osBuild`, `osIncremental`, `securityPatch` | The OS it runs |
| `agentVersion` | The OhrTech Agent's version |
| `online` | Whether the Agent is connected to the OhrTech hub now |

In C# the fields are properties: `DeviceId`, `Serial`, `Fleet`, ...

## When the Agent restarts

The Agent stops now and then: it is updated, say. The library notices and binds again by itself.
Calls made while the Agent is away wait for it, up to 10 seconds; a call the Agent was answering
when it stopped throws `OhrException.Failed`, and you can try it again. Every flow, stream, listener
and event you set up goes on, and the ones that follow a state (Wi-Fi, network, battery, kiosk mode,
updates) get the current state when the Agent is back. To show how the connection stands, follow
[the connection](/device-sdk/access/#the-connection).

## Worked example: a kiosk app

A point-of-sale app that shows your web front end, full screen, locked to the app. Its fleet sets two
things for it: the server it talks to, and whether it starts in kiosk mode.

### 1. Declare the managed configuration

Declare the settings your app reads, with their defaults, in `res/xml/app_restrictions.xml` of your
Android app (`android/app/src/main/res/xml/` in a Flutter or React Native app,
`Platforms/Android/Resources/xml/` in a MAUI app). The portal shows a form for them on the fleet's
and the device's pages.

```xml
<restrictions xmlns:android="http://schemas.android.com/apk/res/android">
    <restriction android:key="server_url" android:restrictionType="string"
        android:title="Server URL" android:defaultValue="https://pos.example.com" />
    <restriction android:key="kiosk_on_start" android:restrictionType="bool"
        android:title="Start in kiosk mode" android:defaultValue="true" />
</restrictions>
```

Point the app's `AndroidManifest.xml` at it, in `<application>`:

```xml
<meta-data android:name="android.content.APP_RESTRICTIONS" android:resource="@xml/app_restrictions" />
```

### 2. Read it and start kiosk mode

`OhrConfig` reads the values the fleet set, or the declared defaults. It doesn't call the Agent and
needs no grant. Starting kiosk mode needs the fleet's `kiosk` grant.

<Tabs syncKey="lang">
<TabItem label="Kotlin">

```kotlin
import android.os.Bundle
import android.util.Log
import android.webkit.WebView
import androidx.activity.ComponentActivity
import androidx.lifecycle.lifecycleScope

class PosActivity : ComponentActivity() {
    private lateinit var web: WebView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        web = WebView(this)
        setContentView(web)
        show(OhrConfig.string("server_url")!!)

        lifecycleScope.launch {
            // The fleet changed the configuration: follow it.
            OhrConfig.changes.collect { show(OhrConfig.string("server_url")!!) }
        }
        lifecycleScope.launch {
            try {
                if (OhrConfig.bool("kiosk_on_start") && OhrAccess.mayUseAsync("kiosk")) {
                    withContext(Dispatchers.IO) {
                        if (!OhrKiosk.state().pinned) OhrKiosk.start(this@PosActivity)
                    }
                }
            } catch (e: OhrException) {
                Log.w("Pos", "Kiosk mode: ${e.message}")
            }
        }
    }

    private fun show(url: String) = web.loadUrl(url)
}
```

`lifecycleScope` is from `androidx.lifecycle:lifecycle-runtime-ktx`; any coroutine scope works.

```java
import android.os.Bundle;
import android.util.Log;
import android.webkit.WebView;
import java.io.IOException;

public class PosActivity extends Activity {
    private final ExecutorService io = Executors.newSingleThreadExecutor();
    private WebView web;
    private Closeable configWatch;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        web = new WebView(this);
        setContentView(web);
        show(OhrConfig.string("server_url"));

        // The fleet changed the configuration: follow it, on the main thread.
        configWatch = OhrConfig.listen(getMainExecutor(), values -> show(OhrConfig.string("server_url")));

        io.execute(() -> {
            try {
                if (OhrConfig.bool("kiosk_on_start") && OhrAccess.mayUse("kiosk")
                        && !OhrKiosk.state().getPinned()) {
                    OhrKiosk.start(this);
                }
            } catch (OhrException e) {
                Log.w("Pos", "Kiosk mode: " + e.getMessage());
            }
        });
    }

    private void show(String url) {
        web.loadUrl(url);
    }

    @Override
    protected void onDestroy() {
        try {
            configWatch.close();
        } catch (IOException ignored) {
        }
        io.shutdown();
        super.onDestroy();
    }
}
```

```dart
class PosPage extends StatefulWidget {
  const PosPage({super.key});

  @override
  State<PosPage> createState() => _PosPageState();
}

class _PosPageState extends State<PosPage> {
  String? _url;
  StreamSubscription<Map<String, Object?>>? _config;

  @override
  void initState() {
    super.initState();
    _load();
    // The fleet changed the configuration: follow it.
    _config = OhrConfig.changes.listen((_) => _load());
    _startKiosk();
  }

  Future<void> _load() async {
    final url = await OhrConfig.string('server_url');
    if (mounted) setState(() => _url = url);
  }

  Future<void> _startKiosk() async {
    try {
      if (await OhrConfig.boolean('kiosk_on_start') &&
          await OhrAccess.mayUse('kiosk') &&
          !(await OhrKiosk.state()).pinned) {
        await OhrKiosk.start();
      }
    } on OhrException catch (e) {
      debugPrint('Kiosk mode: ${e.message}');
    }
  }

  @override
  void dispose() {
    _config?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) => Text(_url ?? '');   // your WebView, loading _url
}
```

```csharp
using Android.App;
using Android.OS;
using Android.Webkit;

[Activity(Label = "POS", MainLauncher = true)]
public class PosActivity : Activity
{
    private WebView web = null!;

    protected override async void OnCreate(Bundle? savedInstanceState)
    {
        base.OnCreate(savedInstanceState);
        web = new WebView(this);
        SetContentView(web);
        Show(OhrConfig.GetString("server_url")!);

        // The fleet changed the configuration: follow it. Raised on the UI thread, where it was added.
        OhrConfig.Changed += OnConfigChanged;

        try
        {
            if (OhrConfig.GetBool("kiosk_on_start") && await OhrAccess.MayUseAsync("kiosk")
                && !(await OhrKiosk.GetStateAsync()).Pinned)
            {
                await OhrKiosk.StartAsync(this);
            }
        }
        catch (OhrException e)
        {
            Android.Util.Log.Warn("Pos", $"Kiosk mode: {e.Message}");
        }
    }

    private void OnConfigChanged(object? sender, OhrConfigChangedEventArgs e) => Show(OhrConfig.GetString("server_url")!);

    private void Show(string url) => web.LoadUrl(url);

    protected override void OnDestroy()
    {
        OhrConfig.Changed -= OnConfigChanged;   // a static event holds its handlers
        base.OnDestroy();
    }
}
```

`OhrKiosk.start` pins the activity's task with Android's lock task, as the system: the app can't be
left, not even by itself. By default the power menu and the status bar's system information stay
available; pass `OhrKiosk.Feature` flags to choose (`OhrKioskFeature` in Dart and TypeScript,
`OhrKioskFeatures` in C#). `OhrKiosk.stop()` ends it only if the fleet lets
kiosk apps leave; otherwise it throws `OhrException.NotAllowed`. The
[kiosk guide](/device-sdk/guides/kiosk/) covers the exit PIN and the watchdog.

### 3. Set it up for the fleet

1. Upload the APK and assign the app to the fleet ([your apps](/management-api/guides/apps/)).
2. On the fleet's Applications tab in the portal, grant the app **Kiosk mode**, or call
   `PUT /v1/fleets/{fleetId}/apps/{appId}/sdk-access` with `{"areas": ["kiosk"]}`
   ([access](/device-sdk/access/#grant-an-area)).
3. Set `server_url` and `kiosk_on_start` for the fleet, or leave the defaults
   ([managed configuration](/device-sdk/guides/managed-config/)).

The device gets the grant and the configuration when it is next online, usually within seconds.
Without the grant, `OhrAccess.mayUse("kiosk")` is false and the app runs without kiosk mode.
